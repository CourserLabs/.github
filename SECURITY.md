# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub's **"Report a vulnerability"** button on the affected repository
(Security → Advisories), or email **security@courserlabs.com** <!-- TODO: confirm address -->.
Include steps to reproduce, the affected version or commit, and the impact you observed.

We aim to:

| Step | Target |
|---|---|
| Acknowledge your report | 2 business days |
| Initial assessment and severity | 5 business days |
| Fix for critical or high issues | 30 days |

We will credit reporters who want credit once a fix ships. Please give us reasonable time to fix an
issue before you disclose it publicly.

## Supported versions

Only the latest release of each product, and the currently deployed version of each service, receive
security fixes.
