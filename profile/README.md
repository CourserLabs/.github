## CourserLabs

We're an AI-driven product studio. We design, build and ship secure mobile and web products for our
clients and for ourselves.

**How we build**

- **Secure by default.** Every repository runs secret scanning, SAST, dependency and IaC checks on every
  change. Infrastructure is code and is reviewed like code.
- **Quality you can measure.** We write typed code, run automated tests, and follow a definition of done
  that agents and humans both meet.
- **AI-native engineering.** We share [agent skills](https://github.com/CourserLabs/skills) that encode
  how we work, so every project benefits from what we learned on the last one.
